# Projektuppgift

Detta projekt är en Angular-applikation utvecklad med TypeScript som en del av en laboration vid Mittuniversitetet. Applikationen gör det möjligt för användaren att söka bland universitetets kurser och skapa ett eget individuellt ramschema.

Kurslistan kan sökas, filtreras och sorteras efter olika kriterier. Användaren kan enkelt lägga till och ta bort kurser från sitt ramschema och se det sammanlagda antalet högskolepoäng.

De valda kurserna sparas i webbläsarens localStorage, vilket innebär att ramschemat finns kvar även efter att sidan laddats om. Applikationen är responsivt utformad för att fungera på både datorer och mobila enheter.
